# heihe

在 IntelliJ IDEA / GoLand 工具窗口中浏览小黑盒社区，使用 IDE 内置 Chromium 和暗色配色。帖子图片和视频保持原色。

## 安装和使用

支持 **IntelliJ IDEA / GoLand 2024.1.x（IntelliJ Platform 241）**，需要含 JCEF 的 JetBrains Runtime。其他 IDE 版本尚未声明兼容。

1. 打开「设置 → 插件 → 齿轮 → 从磁盘安装插件…」。
2. 选择桌面上的最新版插件 ZIP（`heihe.zip` 或带版本号的文件），不需要解压。
3. 应用更新并重启 IDE。
4. 从「视图 → 工具窗口 → 小黑盒」或右侧工具窗口入口打开。
5. 用底部“遮罩”滑块调节内容亮暗：最左保持原亮度，最右完全遮住内容，控制条始终保留。

遮罩使用当前 IDE 的面板灰色；网页、原生控件和滚动条取色一致，切换 IDE 主题时同步更新。

工具栏提供后退、前进、刷新和首页，启用的按钮悬停时显示主题灰色圆角背景。网页顶部隐藏“发布内容”、小黑盒加速器、黑盒语音、黑盒工坊、开放平台、加入我们入口。首页、社区、登录、推荐内容和评论等由原站提供；需要登录时在页面内正常操作。本站帖子弹窗在当前窗口打开，站外弹窗不提供打开入口。

常规竖向滚轮约为原来的 2 倍，横向手势和缩放保留原生行为，嵌套滚动按所在区域及其边界处理。滚动条采用细滑块，鼠标悬停时加宽；右下角交汇处使用暗色背景。

插件显示名为 heihe，工具窗口名保留“小黑盒”，稳定插件 ID 保留以支持覆盖升级。升级后重启 IDE，让已打开的浏览窗口重新创建并加载新资源。

刷新或打开页面时先显示深色加载界面；当前页面样式完成暗色处理后再显示网页。失败时保留深色错误提示，可使用刷新或首页。

## 实现和边界

入口是 [小黑盒社区](https://www.xiaoheihe.cn/app/bbs/home)。窗口首次打开时创建浏览器，窗口内容释放时交由 IDE 释放浏览器资源。隐藏窗口会保留当前浏览页。

主题使用 IDE 背景、文字、边框与链接颜色；如果 IDE 使用浅色外观，网页使用默认 Darcula 配色。样式仅注入小黑盒主文档，原站 SPA 新加载的样式也会适配。窄窗口解除首页的 800px 最小宽度限制，保留帖子信息流；宽度不超过 460px 时仍显示多图帖的左右翻页按钮，可用鼠标切换图片。

本版本以在线浏览为范围；没有离线帖子库、后台定时抓取或账户数据导出。登录状态和页面能力遵循原站及 IDE 浏览器行为。小黑盒可能调整页面结构、登录方式或兼容性，实际登录及全部页面效果需要在安装后确认。

若网页加载失败，可用刷新或首页继续访问。插件错误记录在 IDE 的 `idea.log`，可以从「帮助 → 在资源管理器中显示日志」定位；搜索 `cn.local.heihei` 或 `HeiHei`。主题就绪通知只控制加载界面的显示切换，日志不记录完整网页 URL。

发布 ZIP 仅包含插件类、描述文件、图标与主题资源。SDK 路径由构建时显式传入；发布构建不保留调试源文件和行号信息，归档条目采用固定时间。源码、构建脚本、本文档、配置、运行日志和工作区记录不进入安装包。

## 本机定向打包

在本项目根目录（桌面 heihe）运行：

```powershell
& .\build.ps1 -IdeHome '<IDE_HOME>'
```

将占位符替换为已安装的 IDE 目录。脚本只编译本插件一个 Java 包的两个源文件，读取现成 SDK JAR，不下载或编译 SDK 依赖，不执行测试。临时输出使用 `.tmp/build/heihe/`，安装包输出为本目录 `dist/heihe.zip`。

静态检查与打包成功只覆盖对应检查范围，原站改版、登录和全部页面效果仍需在安装后的 IDE 中确认。
