# Decisions

- 用户要求当前 GoLand 中可开窗口刷小黑盒帖子，暗色并融入 IDE。
- 默认使用原站嵌入浏览，暂不引入批量爬取、离线存储、后台重试或账户数据采集。
- P0 高于所有 skill：不运行大范围测试/构建，不创建测试资产。
- 沙箱 exec 与 Node、浏览器工具初始化失败；只读 exec 经 require_escalated 可用。
- 当前任务不涉及 ECS/Go/服务端，不使用游戏起服、codegen、Robot 验收。
- 最新用户要求完成插件安装包并放到桌面，由用户通过从磁盘安装插件导入。授权范围为该单插件安装产物所必需的一个 Java package 两源文件定向编译与 ZIP 打包；不编译 SDK/依赖/游戏模块，不执行测试。
- 具体打包命令：& .\tools\heihei-goland\build.ps1 -IdeHome 'D:\goland\GoLand 2024.1.6'。脚本内部 javac --release 17 -encoding UTF-8 -proc:none -implicit:none -classpath '<IDE>/lib/*' -d '<repo>/.tmp/build/heihei-goland/<id>/classes' <HeiHeiToolWindowFactory.java> <HeiHeiBrowserPanel.java>，仅两源文件。
- 外站 popup 不自动唤起浏览器，原生区域提示目标域名，由用户点击打开；本站 popup 在当前窗口打开。正常主文档 HTTP(S) 导航保留第三方登录跳转。
- 收口：独立静态审查通过；首次定向编译成功，包已放桌面。没有未解除的阻塞或待裁决知会项。实际安装与网页体验由用户从磁盘导入后确认；不宣称已完成运行验收。
- 0.1.1：用户提供实际白块截图，要求修正原有暗色效果。延续安装包桌面交付；只补界面主题覆盖与 Swing 按钮边框，保留原图像素。沿用已授权单插件两源文件定向打包，不增加测试或测试资产。
- 候选 A 已确认：组件私有 --nav-background 及 white→transparent 渐变被旧逻辑显式跳过。候选 B（整个主题加载失败）排除：实际页面大部分已变暗，IDE 日志记录插件成功加载，无匹配主题错误；不把尚未证实的动态样式时序当根因。
- 已进一步确认标签与 layout-normal 上下边缘是行内浅色背景，已定向覆盖。0.1.1 静态复审、单插件构建、资源归档检查及桌面交付完成；无待裁决项。未执行更新后实机视觉复核，交付说明要求用户安装新版后重启 GoLand 重新创建窗口。
- 0.1.2 用户明确要求：刷新避免先白后暗，颜色准备好后才显示；兼容 IDEA 时使用通用插件名；重新打包桌面 heihe.zip；检查并去除发布包中本机路径和个人信息。此授权覆盖最小显示加载机制与本插件既有单包构建，不授权大范围测试/构建或新增测试资产。
- 兼容范围保持已核实的 IntelliJ Platform 241（GoLand/IDEA 2024.1.x），不静默扩大到未知新版。
- 稳定插件 id cn.local.heihei 保留用于覆盖升级；展示名及包名改 heihe。历史审计文件保留原始证据，绝不打进发布 ZIP。
