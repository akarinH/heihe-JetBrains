# heihe 0.1.3 交付记录

## 使用变化

- 移除插件自带的浮动切换、系统浏览器和外站弹窗打开入口。原生导航只保留后退、前进、刷新、首页。
- 普通竖向滚轮使用 1.25 倍距离；输入框、选择框、多行输入和可编辑区交回原生，横向手势、缩放及已被页面处理的 wheel 不接管。嵌套滚动根据方向、可滚动范围及 overscroll 规则选实际区域。
- 滚动槽固定 14px，滑块通过透明边框从普通可见 4px 变为悬停 10px；交角单独设为暗色，不随悬停改变页面宽度。
- 底部遮罩滑块范围 0–100。0 保持原亮度，100 遮黑网页、工具栏和状态区；控制条本身保留以便恢复。数值只在当前窗口内保存，不落盘。

## 关键调用与实现边界

`HeiHeiToolWindowFactory.java:15` 调无参 Panel 构造，仅这一处创建入口需要同步。Panel 移除了 ToolWindow 字段及所有 BrowserUtil 调用；插件扩展接口、稳定 id 和 platform 241 兼容范围不变，不涉及游戏模块或生成链。

遮罩控制入口 `HeiHeiBrowserPanel.java:203`：滑块更新同一百分比 → 原生内容区域重绘 → `applyShade`（`:339`）更新网页固定黑色层和当前文档的滚动条样式。主文档完成时 `:259` 也先应用遮罩，因此刷新与站外登录跳转保留当前强度。

浏览器原生画布不能依赖 Swing 透明覆盖：`DimPanel.paintChildren`（`:451`）排除正在显示的浏览器矩形，其它原生区域才画黑色层；网页由 DOM 层遮罩。因此 OSR 与非 OSR 均不会重复压暗。100 时先隐藏整个 pageArea，原卡片就绪状态保持；向左恢复只重显同一个区域，不增加 ready 等待。`isPaintingOrigin` 保证子控件悬停重绘也经过遮罩。

`theme.js:117` 的 wheel 回调只沿事件祖先路径查看滚动几何与样式，不全量遍历页面、不读取输入内容、不发送网络请求。241 SDK 没有已确认的原生滚轮倍率属性，未使用虚构的 setProperty 键。

共用 `web/scrollbars.css` 在每个 HTTP(S) 主文档注入一次。审查修正了两处关联路径：textarea 不被接管；内部滚动条已在 DOM 遮罩下，只有根视口的 track/thumb/corner 额外画同值渐变（`:23-24`），避免 50% 档位被叠成 75%。

静态审查原始结论见 `09_controls_review.md:10`。CSS 行为依据和最终包脱敏原始数据见 `10_controls_privacy.md`。
